네이버 SA 소재·심의·URL 대조 시스템

소속
플레이디, 한화손해보험 네이버 검색광고
기간
2026.07 – 2026.09
역할
기획과 구현, Claude Code 사용, 팀 내 배포
  • 소재 등록·운영
  • 랜딩 구조 점검
  • 표현 검수

대조 단위를 실측으로 다시 정의하고 랜딩 URL을 접속 없이 문자열로 대조해, 손으로 하던 심의·URL 검수를 자동 판정으로 바꿨습니다.

문제
보험 광고는 띄어쓰기 하나만 달라도 심의 위반입니다. 심의 엑셀 15개와 계정 소재 844개, 확장소재 1,613개를 회차마다 손으로 맞춰야 했고, 랜딩 URL을 직접 열어 점검하면 그 방문이 utm 값과 함께 광고주 유입 데이터에 섞였습니다.
판단
  • 운영에서 제목과 설명을 자유 조합하는 것을 확인하고 항목별 목록 대조로 재정의, 정상 소재 451개의 오보고를 첫 회차 전에 차단
  • 고객 눈에 보이는 차이는 불일치, 보이지 않는 문자 차이는 일치로 판정 기준 분리
  • UTM 규칙 7종을 HTML 사이트 UTM Builder로 정리해 기준값으로 두고 주소 문자열만 대조
  • API 약관과 사내 지침을 검토해 이미지 대조와 매일 자동 실행은 범위에서 제외
결과
문구 2,802건과 URL 2,249건을 자동 판정합니다. 틀린 심의를 직접 만든 네거티브 테스트 3회에서 탐지율 100%, 오탐 0을 확인했고, 키를 뺀 배포 폴더와 5단계 안내문을 붙여 팀에 배포했습니다.

데일리 SA 검수와 AI브리핑 키워드 검증

소속

기간
2026.07 – 재직 중
역할
기획과 구현, Claude Code 사용
  • 생성형 검색 노출
  • 사실 확인
  • 노출 모니터링

생성형 검색 지면인 네이버 AI브리핑에 실제로 노출되는 키워드만 골라내고, 한 번의 판정을 믿지 않는 재확인 구조로 잘못된 보고를 막았습니다.

문제
데일리 SA 검수는 매일 아침 40분 이상 드는 수작업이었습니다.
판단
네이버 광고는 예산과 시간대에 따라 켜졌다 꺼지므로 한 번의 조회는 믿을 수 없다고 봤습니다. 광고 링크는 추적 주소라 표시 URL과 광고주명으로 자사 여부를 판정했고, 8회 연속 미검출이면 화면 구조가 바뀐 것으로 보고 자동 중단하게 했습니다.
결과
규칙 통과 후보 12,300개를 자동으로 만들었습니다. 통과 처리한 10건을 2회씩 다시 조회하자 4건이 탈락했고, 이후 통과 후보는 재확인을 거쳐야만 보고하게 했습니다. 약관 대조는 업로드한 원문 안에서만 답하는 노트북을 MCP로 연결해 교차 확인했습니다. 이후 데일리 SA 검수가 후보 키워드를 매일 제공하게 되면서 별도 검증 단계는 중단했고, 데일리 검수는 지금도 리포트를 받은 뒤 Claude 스킬로 실행합니다.
